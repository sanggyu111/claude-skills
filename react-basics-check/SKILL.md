# React 기초 점검

React 입문자 코드의 기초 실수 5가지를 점검하고, 각 실수가 왜 문제인지 입문자 눈높이로 설명한다.

## When to Use

- React 컴포넌트 코드의 기초 점검이나 리뷰를 요청할 때
- useState, key, onClick 같은 이벤트 핸들러를 맞게 썼는지 물을 때
- "화면이 안 바뀌어요", "콘솔에 key 경고가 떠요"처럼 기초 실수로 보이는 증상을 물을 때

요청이 성능, Next.js, 스타일, 테스트처럼 위 범위를 벗어나면 아래 "하지 않는 것"을 따른다.

## 점검 순서

### 1. 파일 읽기

사용자가 지정한 파일을 읽는다. 지정이 없으면 `src/` 안의 `.jsx`/`.tsx` 파일을 읽는다.

### 2. 규칙 5개 점검

각 규칙의 "왜"를 결과 설명에 그대로 활용한다.

1. **리스트 렌더링에 고유한 key가 있는가** (index key 지양)
   - 왜: React는 key로 "어느 항목이 어느 항목인지" 구분한다. key가 없거나 index면 항목이 추가·삭제·정렬될 때 체크박스·입력값 같은 상태가 엉뚱한 항목에 붙는다.
   - ❌ `todos.map(t => <li>{t.text}</li>)` → ✅ `todos.map(t => <li key={t.id}>{t.text}</li>)`

2. **state를 직접 수정하지 않는가** (push, 직접 대입 금지)
   - 왜: React는 내용이 아니라 배열/객체가 새것인지(같은 상자인지)를 비교한다. push로 같은 배열을 넘기면 "변화 없음"으로 보고 화면을 다시 그리지 않는다.
   - ❌ `todos.push(x); setTodos(todos);` → ✅ `setTodos([...todos, x]);`

3. **컴포넌트 이름이 대문자로 시작하는가**
   - 왜: JSX는 소문자 태그를 HTML 태그(`div`, `h1`)로, 대문자 태그를 직접 만든 컴포넌트로 해석한다. 소문자로 쓰면 컴포넌트가 화면에 나오지 않는다.
   - ❌ `<greeting />` → ✅ `<Greeting />`

4. **이벤트에 함수를 전달하는가**
   - 왜: `onClick={fn()}`은 클릭할 때가 아니라 화면을 그리는 순간 함수를 실행한다. 그 함수가 state를 바꾸면 무한 반복에 빠질 수 있다.
   - ❌ `onClick={remove(id)}` → ✅ `onClick={() => remove(id)}`

5. **다른 state로 계산 가능한 값을 별도 state로 두지 않았는가**
   - 왜: 같은 정보를 두 곳에 두면 한쪽만 바뀌어 값이 어긋난다. 계산할 수 있으면 렌더링 중에 계산한다.
   - ❌ `const [left, setLeft] = useState(0)` → ✅ `const left = todos.filter(t => !t.done).length`

### 3. 결과 보여주기

이 형식으로 보여준다. 위반이 여러 개면 화면이 안 바뀌는 문제(규칙 2, 4)부터 먼저 쓴다.

```
✅ 통과: 1(key), 3(대문자)
⚠️ 위반: `src/App.jsx:16` — 규칙 2(state 직접 수정)
   문제: todos.push 후 같은 배열을 setTodos에 넘김
   왜: React는 같은 배열이면 변화가 없다고 보고 다시 그리지 않음
   고친 코드: setTodos([...todos, newTodo]);
```

5개 규칙이 모두 ✅ 또는 ⚠️로 표시되면 점검이 끝난 것이다.

## 하지 않는 것

- 코드는 사용자가 원할 때만 수정한다. 점검 결과만 보여주고 "고쳐 드릴까요?"라고 묻는다.
- 5개 규칙 밖의 요청(성능, Next.js, 스타일 등)이면 이 스킬을 멈추고, "이 스킬은 입문자 기초 실수 5가지만 다룹니다"라고 먼저 알린다.
- 대신 범위 밖이 된 키워드(예: performance, nextjs)로 맞는 스킬을 찾는다. "react", "리뷰"처럼 이 스킬에 걸린 단어로는 찾지 않는다.
- 맞는 스킬이 설치돼 있지 않으면 이름과 설치 명령을 알려 주고, 사용자가 원할 때만 설치한다. 원치 않으면 스킬 없이 일반 리뷰로 돕는다.
- React 파일을 찾지 못하면 그렇게 알리고 점검할 파일 경로를 묻는다.
